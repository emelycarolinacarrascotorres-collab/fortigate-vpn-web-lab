# Configuraciones
- `cisco/*_running-config.txt`: salida real de `show run` (secretos redactados).
- `cisco/*_initial-commands.txt`: listados de comandos aportados (pueden diferir del running-config; ver `docs/07-cisco.md`).
- `server/server_commands.txt`: comandos aportados del servidor.
- `fortigate/`: sin CLI aportado.
